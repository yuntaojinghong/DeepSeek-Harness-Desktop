安装与使用

三步开始，无需技术门槛

快速开始

  1. 前往 Releases 下载最新 DeepSeek-Harness-Desktop_*.exe。
  2. 双击安装（默认装到用户目录，无需管理员权限）。
  3. 首次启动填入 DeepSeek API Key，选择工作目录即可开始。

从源码构建

npm install
npm run tauri dev   # 开发模式
npm run tauri build  # 打包安装程序

需要 Node.js ≥ 18、Rust（stable-msvc）与 Visual Studio Build Tools。
